# Foco do Dia

Planner diário para pessoas com TDAH: checklist por turno, alertas na troca de turno e IA que ajuda a fechar o dia e replanejar o que ficou pendente.

> Mini projeto de Engenharia de Software com IA generativa (especialização AKCIT/UFG), construído com boas práticas (requisitos, ADRs, testes, CI) e IA como copiloto. React + Tailwind, Node.js e PostgreSQL. README completo na entrega final.

Documentação do projeto em [`docs/`](docs/).
